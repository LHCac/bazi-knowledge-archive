# 取格條件與天透地藏補充

## 資料定位

本篇整理 2026-09-04 使用者提供的 YouTube 課程文字稿，主題集中在：

- 地支藏干如何與天干統一判讀
- 天透地藏／通根
- 取格的候選條件
- 三合三會對格局氣勢的影響
- 十二長生作為強弱與氣勢的輔助

本篇屬「格局判斷的第二層補充」。

資料庫原有 SOP 仍優先：

```text
先日主、月令。
再看天干透出與地支藏干。
再判日主強弱。
再識別正格，特殊格從嚴。
最後才進一步看取格方式、成敗與行運。
```

---

# 一、地支必須透過藏干與天干一起看

文字稿反覆強調：八字不能只看四個天干，地支中也藏有天干，必須把地支藏干納入同一套十神與五行系統。

因此實戰先做：

```text
1. 列出日主。
2. 對三個其他天干定十神。
3. 列出四支藏干。
4. 對所有藏干再定十神。
5. 檢查哪些十神明透、哪些只暗藏、哪些有根。
```

這與既有資料庫「明透與暗藏都要看」一致。

---

# 二、天透地藏：先理解成「透出而有根」

原始字幕多次辨識成「天透地長」，但上下文明確描述：

```text
天干有某干／某十神，
地支藏干中也有同類，
形成天干外顯、地支有根的結構。
```

因此本資料庫高信度整理為「天透地藏／透出而有根」。

可理解成：

```text
天干：表面可見、容易發揮。
地支：提供根氣、內在支撐。
天透地藏：不只看得到，而且下面有根。
```

但要注意：

```text
有根 ≠ 一定強。
有根還要分月令、主氣中氣餘氣、刑沖破壞、是否被合化。
透出有根 ≠ 自動成格。
```

---

# 三、比肩劫財不直接列入「八格」：只限本課程八格框架

文字稿指出，在它使用的傳統八格框架中：

```text
日主同類的比肩、劫財，不直接作一般八格名稱。
其餘財、官殺、印、食傷等八類十神進入正格討論。
```

本資料庫處理方式：

> 這是「傳統八格」的分類框架，不等於比肩劫財不重要。

比劫仍然要用於：

```text
日主強弱。
建祿、月劫等特殊結構。
財星是否受劫。
合作、競爭、資源分配。
大運流年的扶身或奪財。
```

因此不可誤讀為「比肩劫財沒有格局作用」。

# 四、本次文字稿可保留的取格候選方法

## 1. 天透地藏／透出有根

同一十神在天干透出，又在地支有根，是本課程最基本的取格候選條件之一。

但正式判格仍須回到：

```text
月令是不是支持。
該神是不是有力。
是否清純。
有無被刑沖合破。
全局是否另有更主導的氣勢。
```

---

## 2. 「四見」：列為課程特定規則，不升級為通用核心

文字稿明確解釋「四見」為：

```text
「四」＝一二三四的四。
「見」＝看見的見。
```

其示例是在同一五行／同類十神於天干與藏干中反覆出現，數量形成明顯集中時，亦可作取格候選。

本資料庫只保留為：

> 同一五行或十神高度集中，且有明透時，值得提高其格局候選權重。

但不建立固定「見四個就一定成格」的機械規則，因為仍須檢查月令、根氣、清純度與全局成勢。

---

## 3. 正偏同類混見：暫列低權重補充

文字稿另提到正印、偏印等同五行不同陰陽可以合併看氣勢，並以正偏混合的職業型態作生活化比喻。

這部分派別性較強，本資料庫只採：

```text
正偏同類可一起觀察五行總氣勢。
正偏兩神的十神性質仍應分開。
不能因同五行總量較多就直接合併成同一格。
```

不把「陰陽混見即可取格」升級為核心規則。

---

## 4. 三合、三會成勢：可提高格局候選，但需先確認成局

文字稿認為三合、三會形成完整方局時，力量可很集中，足以成為取格的重要條件。

本資料庫與既有規則整合後採用：

```text
三合、三會若真正成勢，可顯著提高某五行的格局權重。
```

但必須先檢查：

```text
是否三支齊全。
月令是否支持。
有無被嚴重沖破。
是否真的化成該五行氣勢。
該五行對日主與格局是喜是忌。
```

不能只看到三合、三會名稱就直接判格。

# 五、三合與三會：先看「成勢」，不採霸道／王道作硬規則

文字稿用「霸道／王道」比喻三合與三會的氣質差別，這個說法可幫助理解，但不宜作正式吉凶規則。

本資料庫保留更穩定的部分：

```text
三合：由長生、帝旺、墓庫三支構成，形成一種五行局勢。
三會：同一季節方位三支連成一方之氣，季節集中性強。
```

核心仍是：

> 是否成勢、是否得月令、是否對用神有利。

---

# 六、十二長生：看氣勢，不把身強弱直接等同個性

文字稿後段以十二長生談「強弱／輕重」，這個方向可保留。

資料庫既有十二長生：

```text
長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕、胎、養。
```

本次補充：

```text
十二長生可用來觀察某五行或十神在地支中的氣勢階段。
臨官、帝旺等通常表示氣勢較足。
死、絕等表示季節／地支氣勢較弱。
```

但不採文字稿中過度心理化的固定推論：

```text
身強 ≠ 一定有野心、有志氣。
身弱 ≠ 一定沒主見、不想爭。
某十神長生 ≠ 一定家庭上升或某六親成功。
```

日主強弱首先是五行承載問題，性格只能作第二層觀察。

---

# 七、固定十五年「時效」不納入核心

文字稿大量使用年、月、日、時各管十五年，並把天干地支的透藏跨柱延伸成固定年齡區間。

本資料庫不採為通用硬規則。

只保留：

```text
年柱偏早年／家庭背景。
月柱偏成長、青年、職涯根基。
日柱偏自己、核心關係與中段人生。
時柱偏後期成果、子女與晚年。
```

若要判具體年份，仍以大運、流年為主，不用四柱固定十五年取代行運。

---

# 八、實戰使用順序

加入本次資料後，取格可依下列順序使用：

```text
1. 日主、月令先定。
2. 天干透出與地支藏干全部列出。
3. 判日主強弱與根氣。
4. 先看月令是否形成正格候選。
5. 再看透出有根、十神集中、三合三會是否加強某一候選。
6. 比劫、建祿、月劫、從格等另依既有特殊規則處理。
7. 取格後再談用神、喜忌、成敗救應。
8. 最後看大運流年是否助格或破格。
```
