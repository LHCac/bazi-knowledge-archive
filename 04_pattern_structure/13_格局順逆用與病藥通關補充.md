# 格局順逆用與病藥通關補充

## 資料定位

本篇整理 2026-09-04 使用者提供的 YouTube 課程文字稿，主題集中在：

- 格局不是單純吉凶標籤
- 順用、逆用的基本思路
- 正官格作為示範
- 格局之「病」與「藥」
- 通關用神、病藥用神
- 大運流年如何引動成敗

本篇不取代既有《十神格局總論》，而是補充「怎麼思考格局成敗」的方法。

---

# 一、格局本身不是成功保證

文字稿反覆指出：

```text
同一種格局，有人成、有人成不了。
格名本身不決定富貴。
真正要看的是格局是否按照它需要的方式被使用、保護、制化。
```

本資料庫採用：

> 格局是命局結構，不是吉凶標籤。

所以判格後還要繼續：

```text
看日主能否承擔。
看格神是否有根有力。
看有無破格因素。
看有無相神／救應。
看大運流年是助成還是破壞。
```

---

# 二、日主要「能任格」，但身強不等於有野心

文字稿把日主比喻成「主席」，格局像客觀環境；主席要有能力，才能承接格局。

這個比喻可保留為：

```text
格局有條件，日主也要有承載力。
財官再好，日主太弱也可能任不起。
日主有根、印比扶身，通常較有承載基礎。
```

但不採文字稿中把身強直接等同「有志氣」、身弱等同「沒主見」的固定人格判斷。

本資料庫統一：

> 身強身弱先談五行承載，不直接等同心理人格。

---

# 三、順用與逆用：先學「保護」與「制化」

文字稿將八格分成順用、逆用兩種思路，並以正官、七殺作最清楚的例子。

本資料庫先保留概念，不由本次字幕重建完整八格順逆表。

## 順用

可理解為：

```text
格局核心本身值得保護、扶持、流通，
避免直接傷害格神。
```

例如正官格：

```text
官星為格局核心時，不喜傷官直接破官。
```

## 逆用

可理解為：

```text
格局核心本身力量較猛烈，需要制、化、洩，使其可用。
```

例如七殺：

```text
七殺強時，可用食神制殺，或用印化殺。
```

核心不是背「吉神／凶神」，而是問：

> 這個格神現在需要保護，還是需要制化？

---

# 四、正官格：本次文字稿的示範框架

文字稿用正官格示範格局喜忌，與既有資料庫大致一致。

可保留的核心：

```text
1. 忌傷官直接破官。
2. 官殺混雜需看去留與制化。
3. 官星被合、被沖時，要看是否傷到格局核心。
4. 日主要有承載力，不能完全無根無助。
5. 財、印等能否形成生扶與保護，要看全局配置。
```

注意：

```text
傷官見官 ≠ 一定發災。
官殺混雜 ≠ 一定婚姻出事。
官被沖合 ≠ 一定丟工作。
```

這些都只是「可能破格的條件」，要看有無救應與行運。

# 五、病藥法：命局有問題，不等於沒有救

文字稿很值得保留的一個觀念是：

> 真實命局通常不會完全乾淨，重點不是「有沒有病」，而是「有沒有藥」。

本資料庫將「病」理解為：

```text
破壞格局核心的因素。
讓五行失衡的因素。
讓用神受傷的因素。
讓格神混雜、受沖、受剋的因素。
```

「藥」則是：

```text
制掉病神。
化掉直接衝突。
通關讓兩方力量改走生化路徑。
扶起日主承擔格局。
```

---

# 六、傷官見官的兩種救應示範

文字稿用「傷官見官」說明兩種思路，這部分很有實戰價值。

## 1. 財星通關

原理：

```text
傷官 → 生財 → 財生官
```

原本：

```text
傷官直接剋官
```

加入財星後：

```text
傷官的力量先流向財，
財再生官，
直接衝突被轉成連續相生。
```

這就是「通關」思路。

但是否真能通關，仍要看：

```text
財星是否有力。
財是不是被比劫破壞。
日主能不能任財官。
全局是否還有其他阻隔。
```

---

## 2. 印星制傷官

原理：

```text
官 → 生印
印 → 制食傷／護官
```

印星介入後，可降低傷官直接破官的力量。

這是「病藥」思路。

但不能看到印就自動判救成，仍要看：

```text
印星是否有根有力。
有沒有財星破印。
印是否過重反成新的失衡。
```

# 七、官殺混雜：核心是去留，不是直接斷事件

文字稿提到可利用合去其中一方，使官殺不再同時混雜。

本資料庫保留為：

```text
官殺混雜先看哪一個有力、哪一個應留。
若有合、制、化能使一方去而一方清，可視為清格方向。
```

但不機械使用：

```text
看到合就一定合得走。
官殺混雜就一定感情混亂。
行運一來就一定去掉某神。
```

必須看合化條件、位置、力量與月令。

---

# 八、沖與合：要看有沒有真正傷到格神

文字稿把正官受沖、受合作為格局破損的重要情況。

本資料庫整合後採：

```text
格神被合：可能牽制、被奪、失去專一性。
格神被沖：可能形成變動、破壞、位置不穩。
```

但：

```text
合不一定化。
沖不一定凶。
```

只有當沖合真的破壞用神、格神、根氣或整體結構時，才提高「破格」權重。

---

# 九、大運流年可以帶來「病」，也可以帶來「藥」

文字稿提出一個很重要的動態觀念：

```text
原局有病，大運流年可能把病神制掉、合走、通關，形成一段較順的時期。
原局本來清純，大運流年也可能加入傷官、七殺、沖合等因素，暫時破壞原局。
```

因此：

> 原局決定底盤，大運流年決定何時被強化、修復或破壞。

這與資料庫既有「先原局，後大運流年」一致。

---

# 十、同一十神不是越多越好

文字稿後段提到「多根」「官多」等問題。

本資料庫只保留普遍原則：

```text
同一十神多，不代表功能一定更強、更吉。
過多可能形成混雜、偏枯、壓力或失去流通。
```

所以仍要看：

```text
是否得令。
是否有根。
是否清純。
是否過量。
是否有制化。
```

不採固定「幾個官就不貴、幾個財就不富」的數量斷語。

---

# 十一、本次不納入核心的內容

文字稿中有不少時代性、派別性或過度具體的斷法，本資料庫不升級為核心規則：

```text
身強一定有野心，身弱一定沒主見。
正官格一定做官。
正官被沖一定丟工作。
傷官見官一定有災。
官殺混雜一定怕事或婚姻混亂。
固定四柱十五年分段可以直接斷事件。
女人只重老公小孩、財不重要。
以清朝官僚階級作現代人生價值標準。
```

這些只保留為原講者的時代／教學語境，不作現代實戰判決。

# 十二、實戰判格後的 SOP

加入本次內容後，格局判斷可用：

```text
1. 先定日主、月令、強弱。
2. 取格。
3. 判格神是需要順用保護，還是需要制化。
4. 找破格因素，也就是「病」。
5. 找相神、通關、制化，也就是「藥」。
6. 看病藥是否真的有力、有根、位置有效。
7. 再看大運流年何時帶病、何時帶藥。
8. 最後才落到職涯、財運、感情等現實問題。
```
