# 一、財格：正偏財可以合看格局功能，但十神性質仍分開

文字稿指出，正財、偏財在性格與六親象意上不同，但作為「財格」時，都屬於以財星為核心的順用結構。

本資料庫採用：

```text
正財、偏財可共同觀察「財的總氣勢」。
但正財、偏財的性質仍應分開解釋。
正偏財同見，不直接等於混雜破格。
```

財格真正要看：

```text
日主是否能任財。
財星是否得令、有根、有力。
比劫是否過重奪財。
財是否被合住、沖破或受制。
有無食傷生財、官星護財等流通。
```

## 比劫與財格

文字稿把比劫視為財格的重要破壞因素，方向與既有資料一致，但不採「見比劫就一定破產」。

資料庫統一：

> 比劫過重、財為喜用且缺乏制化時，才提高競爭、分財、資源被奪的風險。

可觀察的救應包括：

```text
食傷通關：比劫 → 食傷 → 財。
官殺制比劫：在日主與官殺能承受的前提下，降低比劫爭財。
```

是否成立仍須看各神有無根、有沒有新的副作用。

---

# 二、財星被合、被沖：先看「資源流動性」，不要直接斷破產

文字稿將「財帶合」描述為錢被綁住、不自由，例如資產落在公司、不動產或難以立即動用。

這個生活化取象可保留為低至中權重觀察：

```text
財被合：資源被綁定、用途受限、共同持有、資產不易流動。
財被沖：資源結構變動、收支波動、資產重新配置。
```

但：

```text
財被合 ≠ 一定沒錢。
財被沖 ≠ 一定破產。
```

要先確認合是否成立、沖是否傷到財根，以及財是不是喜用。

---

# 三、印格：核心是生身與保護，財破印要看能否通關

文字稿認為印格屬順用，印星主要功能是生身、庇護與承接。

可保留：

```text
印星有力，日主得到支持。
財星直接剋印，可能形成財破印。
官殺可形成財 → 官殺 → 印的通關路徑。
```

因此若財印直接衝突，可先檢查：

```text
官殺是否能通關。
財是否真的過強。
印是否為格局核心或用神。
日主本身是否已過旺。
```

文字稿中「印格不需要日主強」不作硬規則。

本資料庫修正為：

> 印本身能扶身，因此印格通常比財官格更容易補足日主承載，但仍須判全局強弱，不能省略身強弱。

# 四、食神格：保護食神本身，再看是否能生財

文字稿把食神格列為順用，並強調：

```text
食神本身要能保留。
食神可生財。
偏印直接制食神時，要防「梟印奪食」類問題。
```

本資料庫與既有規則整合：

```text
身強食旺、財有根，食神生財較完整。
偏印過強直接壓制食神，可能使輸出、才華、產能受阻。
印太重而食神受制時，可檢查比劫通關：印 → 比劫 → 食神。
```

但比劫若又造成奪財，也可能產生新的病，所以不能只看一段生剋鏈。

# 五、七殺格：四種常見處理方向

文字稿將七殺格視為典型「逆用／制化」格，並提出四個常見方向。

本資料庫高信度整理為：

```text
1. 食神制殺。
2. 殺印相生／印化殺。
3. 身殺兩停。
4. 羊刃駕殺。
```

## 1. 食神制殺

```text
七殺過猛，以食神制殺。
```

要看食神是否有力，並防印過重奪食。

## 2. 殺印相生／印化殺

```text
七殺 → 生印 → 印生身。
```

把直接壓力轉成支持、資格、責任或制度資源。

## 3. 身殺兩停

可理解為：

> 日主與七殺力量大致可以互相承擔，不是一方完全壓倒另一方。

這不是固定吉格，仍要看清純、根氣與行運。

## 4. 羊刃駕殺

日主旺而有刃時，官殺可用來制衡過旺比劫之氣。

仍須避免：

```text
刃太重而殺無力。
殺太重而身不能任。
食傷把官殺剋盡。
```

# 六、偏印格、傷官格：保留「制化思路」，不採唯一答案

文字稿把偏印、傷官歸入需要制化的一側，並有「偏印用財制」「傷官需看財印」等說法。

資料庫只保留方向：

```text
偏印過重：可看財制印、比劫通關、是否奪食。
傷官過重：可看傷官生財、傷官配印、是否傷到官星。
```

不採：

```text
偏印格只有偏財一種解法。
傷官格見官就一定有災。
```

仍以全局病藥為準。

---

# 七、建祿、羊刃：本質先看日主強旺，再另取財官食傷

文字稿把建祿、羊刃視為特殊的強身結構。

這與既有資料一致：

```text
建祿、月劫、羊刃多代表日主已有較強根氣。
通常不再以印比作第一優先。
更常從財、官殺、食傷中尋找流通與制衡。
```

但不採文字稿中「有七殺就是好命」等直接斷語。

---

# 八、三奇、魁罡：只作特殊象意，不直接判一生好壞

文字稿後段談三奇、魁罡，並附帶大量「一生沒問題」「女命一定婚姻差」等強烈斷語。

本資料庫只保留低權重象意：

```text
三奇：可作特殊組合、貴人與清奇氣勢的輔助觀察。
魁罡：可觀察剛強、決斷、原則感、直率或強勢氣質。
```

全部排除：

```text
有三奇就一定逢凶化吉。
魁罡一定不能受沖。
女命魁罡一定婚姻失敗。
魁罡從業或飲食禁忌可以決定吉凶。
```

特殊神煞不能高於月令、強弱與格局。

# 九、從格：成立條件仍從嚴

文字稿將「全局幾乎同一氣勢」引到從格、真從、假從。

本資料庫維持既有規則：

```text
從格必須氣勢非常純粹。
日主不可有足以逆勢的根與生扶。
稍有關鍵逆勢之神，就要慎判假從或不從。
```

不因五行數量看起來偏一邊，就直接判從格。

# 十、調候與格局要分層

文字稿把調候看得非常重要，尤其反覆以「夏熱需水、冬寒需火」作教學例子。

本資料庫保留：

> 寒暖燥濕是格局以外的另一層條件，極端夏冬命局尤其值得檢查調候。

但不採：

```text
夏生一定用水。
冬生一定用火。
有調候用神就一定富貴。
沒有調候就一定無法有大成就。
```

具體調候仍要依日主、月令、全局寒暖燥濕與五行配置判斷。
