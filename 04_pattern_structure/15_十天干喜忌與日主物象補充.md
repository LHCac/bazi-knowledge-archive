# 一、這套課程把「喜忌」分成不同層次

文字稿明確區分三個方向：

```text
1. 日主本身的喜忌。
2. 格局喜忌。
3. 調候喜忌。
```

本資料庫採用這個「分層」觀念，但不把三者混成同一套答案。

## 1. 日主喜忌

這套課程主要用十天干的自然物象，描述一個人較容易感到「合適、順手、有發揮感」的方式。

可理解為：

```text
日主喜忌 = 某種生活／做事方式的象徵性適配。
```

它比較接近「怎麼做比較有發揮感」，而不是直接等於：

```text
富貴。
一定成功。
一定適合某職業。
一定有某種人格。
```

## 2. 格局喜忌

仍回到：

```text
月令。
日主強弱。
格局成敗。
用神、相神、忌神。
病藥與制化。
```

格局喜忌權重高於單一日干物象。

## 3. 調候喜忌

處理寒暖燥濕，例如冬寒、夏熱等環境問題。

調候可與十神同時存在，但不能因某字有調候作用，就直接推成某六親、職業或感情結果必然好。

# 二、十天干物象：只作教學模型

課程以自然／物理形象區分十干，這種方法適合幫助理解，但不是實證人格分類。

| 日干 | 課程常用物象 | 可保留的取象方向 |
|---|---|---|
| 甲 | 大樹、木材 | 生長、成材、修整 |
| 乙 | 花草、藤木、盆景 | 滋養、環境、細緻培養 |
| 丙 | 太陽、自然之火 | 光、顯現、熱度、擴散 |
| 丁 | 燈燭、爐火、人工火 | 持續燃料、聚焦、維持 |
| 戊 | 高山、大土 | 承載、規模、聚集、結構 |
| 己 | 田園土、園圃 | 培育、濕潤、耕作、調理 |
| 庚 | 生鐵、礦鐵、粗金 | 鍛鍊、成器、加工 |
| 辛 | 珠玉、首飾、精細金 | 打磨、清潔、精緻化 |
| 壬 | 江河、奔流之水 | 流動、方向、收束、渠道 |
| 癸 | 湖水、雨露、較靜之水 | 滋潤、蓄水、來源、細流 |

資料庫使用限制：

> 物象只用來協助描述「作用方式」，不能反過來取代旺衰、格局、十神與行運。

# 三、課程中的「十天干喜忌配對」

依兩份文字稿前後文，可高信度還原出這套課程常用配對：

```text
甲不離庚。
乙不離丙癸。
丙不離壬。
丁不離甲。
戊不離甲。
己不離丙癸。
庚不離丁。
辛不離壬。
壬不離戊。
癸不離庚辛。
```

## 本資料庫的定位

這十條只標記為：

> **該課程的十天干物象喜忌口訣／教學配對。**

不升級為「所有子平流派通用的固定用神表」。

不能寫成：

```text
甲命沒有庚就一定失敗。
乙命沒有丙癸就一定無成就。
丙命見壬就一定富貴。
丁命見甲就一定高命。
戊命見甲就一定有權。
庚命見丁就一定成器。
辛命見壬就一定好命。
壬命見戊就一定成功。
癸命見庚辛就一定有靠山。
```

真正判斷仍須問：

```text
這個字是否得令、有根、透出？
力量是否適量？
有沒有被合去、沖剋、受制？
它在本命是喜神還是忌神？
它是否破壞原局其他更重要的結構？
```

# 四、物象配對的教學含義

## 甲木與庚金

課程用「大樹需要修剪、木材要經加工才成器」來說明甲庚。

可保留為：

```text
甲：原始生長與方向。
庚：修整、規範、切割、成形。
```

但庚太重也可能變成過度砍伐，所以「有庚」不等於庚越多越好。

## 乙木與丙、癸

課程把乙木想成花草／盆景，需要陽光與水分。

可保留：

```text
丙：光照、可見度、外在環境。
癸：細緻滋養、維持生長。
```

但是否真為喜用，仍看全局。

## 丙火與壬水

課程以太陽火與水火既濟作象。

可保留：

```text
壬對丙：冷卻、調節、形成張力與邊界。
```

不採「丙見壬必成功」或「丙一定適合高風險競爭」。

## 丁火與甲木

丁火以燈燭、爐火為象，需要燃料維持。

可保留：

```text
甲木：持續供給、燃料、支撐丁火發揮。
```

不採「丁無甲必無成就」。

## 戊土與甲木

戊以高山土為象，課程用山上有樹來表達「土要有生機與作用對象」。

可轉化為：

```text
甲木：規範、開發、使大土有方向與用途。
```

這個取象尤其適合做「作用方式」的假設，不宜直接變成人際／職涯定論。

## 己土與丙、癸

己以田園土為象，課程強調日照與水分。

可保留：

```text
丙：溫暖、日照。
癸：濕潤、灌溉。
```

但水火仍須適量；過乾、過濕都不能只靠口訣判斷。

## 庚金與丁火

庚以生鐵、粗金為象，丁火作鍛鍊。

可保留：

```text
丁：鍛鍊、熔煉、讓原始材料成器。
```

若火太強、金太弱，也可能反成損傷。

## 辛金與壬水

辛以珠玉、飾金、精細金為象，課程用「清洗、淘洗」說明壬水作用。

可保留：

```text
壬：清理、流動、洗鍊、去除雜質。
```

不採「辛一定怕火」等機械化結論；仍看格局與季節。

## 壬水與戊土

壬以江河奔流為象，戊如堤岸、河道、收束。

可保留：

```text
戊：界線、渠道、收束與承載流動。
```

但土太重也可能壅塞水勢。

## 癸水與庚辛

癸以較靜的水、湖水、雨露作象，課程強調水要有來源，以金作水源象。

可保留：

```text
庚辛：來源、補給、使水不枯竭的象徵。
```

但「金生水」仍須放回季節、強弱與整局判斷。

# 五、這批資料最有價值的新觀念：喜不一定一路都喜

文字稿進一步談到「先喜後忌／先忌後喜」的概念。

資料庫可轉化成：

```text
喜神出現 ≠ 從此一路吉。
喜神太過、受傷、被合、被沖、被其他結構破壞，仍可能失去作用。
忌神出現 ≠ 一定災。
忌神若被制、被化、被通關，也可能轉成可用條件。
```

這與既有病藥、制化、成敗救應邏輯一致。

例如：

```text
甲喜庚作修整，但庚過重，反成砍伐太過。
庚喜丁鍛鍊，但土過厚把庚埋住，可能只是能力不易顯露，而非直接凶災。
壬喜戊收束，但戊過重也可能堵水。
```

所以「喜忌」必須看**劑量、位置、根氣與互動**，不能只看字有沒有出現。

# 六、「好命」與「適配／成就方式」要分開

文字稿反覆提出一個值得保留的區分：

```text
外在條件好，不代表本人一定喜歡這種生活。
收入高，不代表工作方式一定適配。
關係條件好，不代表相處一定舒服。
```

本資料庫現代化為：

> 日主物象喜忌可用來補充「偏好的運作方式」，但不能拿來取代實際能力、興趣、資源、人格、職場條件與關係互動。

因此職涯題可分成：

```text
能不能做：看能力、資源、格局承載、現實條件。
做不做得久：看長期適配、壓力與行運。
喜不喜歡：只能把日主物象當假設，再由本人經驗驗證。
```

感情題同理：

```text
條件好 ≠ 相處好。
有夫星／妻星 ≠ 一定合適。
十干喜忌只能提出「互動偏好」假設，不能代替真實行為。
```

# 七、仁義禮智信：只保留為傳統五行德性象徵

課程也使用：

```text
木主仁。
火主禮。
土主信。
金主義。
水主智。
```

本資料庫只保留為傳統文化象徵。

不能直接推：

```text
木日主一定心軟。
火日主一定有禮。
土日主一定守信。
金日主一定講義氣。
水日主一定聰明。
```

人格仍需多條件與現實行為驗證。

# 八、本批文字稿明確不採的內容

以下全部排除為核心規則，最多只作歷史／講者個人教學背景：

```text
男命怕沖、女命怕合。
女命合多就一定婚姻不好。
官多不貴、財多不富可直接斷一生。
某日干固定適合或不適合某職業。
某日干一定有某人格、野心、膽量或人際模式。
某個十干組合可直接推特定社會階級、財富數字或官位。
某日干配某十神就是「最凶」。
用單一命盤結構直接預言自殺、死亡或重大災禍。
固定十五年、四十五年即可取代大運流年。
用古代性別角色決定現代人的婚姻價值。
```

尤其自傷、自殺、死亡類說法，依資料庫既有高風險斷語規則，只能保留為古籍／課程案例背景，不能作確定預言。

# 九、實戰使用順序

未來若要使用這套「十天干喜忌」，統一放在第二層：

```text
1. 排四柱、定日主。
2. 看月令與身強弱。
3. 看根氣、透藏、刑沖合會。
4. 定格局、用神、喜忌、病藥。
5. 再看十天干物象喜忌，生成「適配方式」假設。
6. 用十神、宮位把象意放到具體問題。
7. 看大運流年是否引動。
8. 回到現實行為與當事人實際感受驗證。
```

若日主物象喜忌與格局用神衝突：

> **優先服從月令、強弱、格局、用神與全局制化。**

十干物象只作補充，不反客為主。
