# 04_pattern_structure：格局、旺衰、用神喜忌

本資料夾存放八字格局與命局結構分析資料。

## 已整理補充

- `10_貴人吉神總整理.md`：天乙、天德、月德、天赦、福星、天廚、天官、太極、學堂、三奇等吉神的輔助取象與限制。
- `11_常用神煞定位與使用限制.md`：由 YT 文字稿雙重校驗後整理的孤辰寡宿、大耗、貴人、羊刃、祿、將星、華蓋、驛馬、劫煞、亡神等現代化取象與使用邊界。
- `12_取格條件與天透地藏補充.md`：整理地支藏干、天透地藏／通根、四見、三合三會與十二長生在取格時的使用方式與限制。
- `13_格局順逆用與病藥通關補充.md`：整理格局順用／逆用、正官格示範、病藥法、通關用神與大運流年對格局成敗的影響。
- `14_八格順逆用與特殊格補充.md`：補充財格、印格、食神格、七殺格的順逆用與制化，以及建祿、羊刃、三奇、魁罡、從格與調候的使用限制。
- `15_十天干喜忌與日主物象補充.md`：整理十天干自然物象、日主喜忌／格局喜忌／調候喜忌分層，以及十干喜忌配對的第二層使用方式與限制。
- `16_五行喜忌取代與象徵性應用限制.md`：整理五行延伸到方向、顏色、物品等象徵的「五行取代」方法，並明確限制其不能取代命局結構、現實關係、醫療或安全判斷。
- `17_用神語義分層與月令取用補充.md`：整理不同語境下「用神」可能指格局核心、相神救應、扶抑、調候或行運作用，並補充月令優先、司令分日、透干、強弱比較對象與無根的使用限制。
