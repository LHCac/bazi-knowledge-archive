# 刑沖合會連鎖與事件餘波補充

## 資料定位

本篇整理 2026-09-04～09-05 使用者提供的 YouTube 課程文字稿，重點放在：

- 刑沖合會在原局、大運、流年間的實戰定位
- 沖合雙方力量比較
- 半刑、半合、半會等不完整結構的使用限制
- 相鄰年份之間的連鎖作用
- 「觸發年」與「事件後續」的區分
- 流年判讀不能只做單年吉凶二分

本篇不取代 `03_stems_branches/00_干支五行與刑沖合會.md` 與 `05_luck_cycles/04_沖合定位與問題導向判讀補充.md`，只補充進階實戰層。

資料庫原則仍是：

```text
先原局，後大運，再流年。
先看月令、強弱、格局與喜忌。
刑沖合會只描述作用方式，不直接等於事件名稱。
```

---

# 一、沖不只看「有沒有」，還要比較雙方力量

文字稿用多組例子說明：同樣是沖，兩邊力量不同，結果也不應完全相同。

本資料庫採用的穩定版本：

```text
沖的兩方都要看：
- 是否得令
- 是否有根
- 是否透干
- 是否受生扶
- 是否受制
- 是否為格神、用神或忌神
```

所以：

```text
兩強相沖 ≠ 一定大凶。
一強一弱 ≠ 弱方一定完全消失。
旺沖衰只能作力量方向提示，不能機械寫成「弱者必被沖掉」。
```

真正要問的是：

> 哪一方在這次作用後失去功能、被牽動、被打開，或反而得到新的流通？

---

# 二、半刑、半合、半會：統一降為低權重輔助

文字稿進一步談到：

```text
三刑只出現其中兩支時，可被某些系統稱為「半刑」。
三合、三會未滿三支時，某些組合仍可形成「半合／半會」。
```

課程本身也承認這些不完整結構的力量較弱，實戰上常不作主要判斷。

本資料庫統一：

```text
完整三刑、三合、三會 > 不完整的半刑、半合、半會。
```

半刑、半合、半會只在以下情況提高權重：

```text
1. 月令支持。
2. 相關五行已有明顯根氣。
3. 天干有相應透出。
4. 大運流年補足缺字。
5. 對格神、用神、夫妻宮等重要位置有實際作用。
```

不採：

```text
只要兩支碰到就等同完整三合。
半合一定化局。
半刑一定有災。
兩個半局一定可以機械相加成完整一局。
```

若未來要建立更精細的半合／半會表，需另外指定流派與來源再校驗。

---

# 三、天干與地支要一起看，不只看地支名稱

文字稿多次用「地支看起來相同，但天干不同，結果不同」作例子。

本資料庫保留：

```text
地支出現沖、合、刑、會後，還要再看同柱與相關柱的天干。
```

原因是天干會改變：

```text
十神主題。
力量來源。
是否有生扶或通關。
是否形成明合暗沖、表合內沖等複合結構。
```

因此：

> 不能只用「某兩支相沖」就完成判讀。

---

# 四、原局、大運、流年的作用具有「連鎖性」

本批文字稿最值得保留的新觀念之一，是：

> 相鄰年份不能完全切成彼此獨立的吉年／凶年。

例如：

```text
前一年形成合，下一年形成沖；
前一年形成沖，下一年得到合或救應；
連續數年反覆作用同一個宮位或十神。
```

這時應解釋成一段「事件鏈」，而不是：

```text
第一年好。
第二年壞。
第三年又好。
```

較好的寫法是：

```text
第一年：形成條件或開始。
第二年：結構改變、衝突或結果浮現。
第三年：延續、收尾、修復或轉向。
```

每一步仍須回到原局喜忌與現實事件驗證。

---

# 五、區分「觸發年」與「事件持續時間」

文字稿用訴訟、破產、關係變化等例子強調：某一年引發一件事，不代表流年一過，後果就自動消失。

本資料庫正式採用這個分層：

```text
觸發年：某個刑沖合會把事件推入明面。
發展期：事件依現實機制繼續發展。
餘波期：即使歲運符號已經離開，後果仍可能存在。
修復期：新的條件出現後，事情才逐步結束或轉向。
```

例如：

```text
流年沖到工作結構 → 可能啟動轉職、爭議或組織變動。
但真正離職、交接、訴訟、財務結算可能跨年完成。
```

所以：

> 流年是時間觸發器之一，不是事件期限計時器。

---

# 六、不能把「下一個好流年」當成自動復原鍵

文字稿有「壞事要等後面好流年才真正結束」的說法。

本資料庫只保留較穩定的部分：

```text
後續歲運若帶來救應、通關、支持或新資源，確實可能改善前一段的問題。
```

但不採：

```text
一定要等六合／三合年事情才結束。
好流年一到就一定復原。
壞流年過完就一定停止惡化。
```

事件持續多久，仍受法律、財務、醫療、關係、工作流程與當事人決策影響。

---

# 七、「新事／舊事」仍只作低權重來源假說

本次文字稿再次提出：

```text
歲運直接作用原局 → 偏既有題材被引動。
流年主要作用大運 → 偏這一步大運中新出現的題材。
```

沿用 `04_沖合定位與問題導向判讀補充.md`：

> 這是「新舊事件來源假說」，不是通用定律。

若同時作用原局與大運，可優先理解成：

```text
舊題材與新環境同時被牽動。
```

最後仍要用當事人的真實經歷確認。

---

# 八、固定十五年、三十年、七年半分段不升級

文字稿再次使用：

```text
兩柱合看三十年。
前十五年、後十五年分輕重。
某些結構再切七年半。
```

本資料庫仍視為課程／流派特定時間模型，不作核心應期規則。

統一：

```text
四柱位置可以提供人生階段象意。
具體時間以大運、流年為主。
固定十五年／三十年／七年半不可取代行運。
```

# 九、實戰風險管理：把命理翻譯成可行動建議

文字稿有一個值得現代化保留的做法：如果已知某段時間可能有較強衝突，與其只說「今年犯沖」，不如回到現實問題提前處理。

可轉成：

```text
工作衝突：提早確認合約、權責、交接與備案。
財務衝突：降低槓桿、保留現金流、避免逾期與高風險承諾。
合作衝突：把口頭約定改成明確條款。
關係衝突：提早處理已存在的溝通與界線問題。
健康／安全：回到醫療、休息、交通與工作安全管理。
```

這是「風險管理」，不是用歲運保證事件。

# 十、行運連鎖判讀 SOP

後續遇到連續數年刑沖合會，可用：

```text
1. 先定原局日主、月令、格局、喜忌。
2. 找出被作用的十神、宮位與根氣。
3. 看大運提供的十年背景。
4. 逐年標記流年形成的沖、合、刑、會。
5. 比較雙方力量，不只記名稱。
6. 看前一年是否已形成事件前因。
7. 區分觸發、發展、餘波、修復四階段。
8. 半刑、半合、半會只作低權重補充。
9. 新事／舊事只作來源假說。
10. 最後用現實時間線驗證。
```
