# 一、流月的角色：縮小時間窗口，不改寫原局

資料庫統一時間層級：

```text
原局：長期底盤。
大運：十年左右的階段背景。
流年：年度引動。
流月：月度細化與短期觸發。
```

因此：

> 流月的主要用途，是把原本已經存在於原局、大運、流年的題目，進一步縮小到某幾個月觀察。

不能反過來：

```text
只看某個流月，就推翻整年判斷。
只因某月有財，就判當月一定發財。
只因某月沖夫妻宮，就判當月一定分手。
```

---

# 二、先有年度題目，再找月度落點

文字稿一開始就指出：一年有十二個月，只用流年一個干支去粗分某幾個月，容易過度簡化。

本資料庫採用：

```text
1. 先定原局。
2. 再看大運。
3. 再看流年今年主要引動什麼。
4. 最後用流月縮小「什麼時候比較容易浮上來」。
```

例如：

```text
流年已形成工作變動主題 → 流月再找面試、交接、簽約、衝突較集中的月份。
流年已形成財務壓力 → 流月再找付款、資金調度、結算較集中的月份。
流年已形成關係變化 → 流月再找互動升溫、談承諾、爭執或重新協商較明顯的月份。
```

流月是「時間定位器」，不是獨立事件產生器。

# 三、五虎遁：流月排干支的基礎，但本批不重建口訣表

文字稿明確提到「五虎遁」，用來由年干推寅月月干，再順排十二個月。

同時也指出：

```text
一年十二個月。
五年合計六十個月。
月柱干支會形成六十甲子的循環。
```

這是流月排盤的基礎概念。

但本批字幕對五虎遁口訣與干支例字的 ASR 失真較重，因此：

> 本篇不從這份字幕重建完整五虎遁表。

日後若要建立「流月排法標準表」，應另外用曆法／干支排盤資料校驗。

# 四、流月與大運：可作重要初篩，但不是唯一作用方向

本課程非常強調「流月先對大運看」，甚至提出流月與原局、流年直接關係較低的說法。

這屬於講者／流派的實戰模型，本資料庫不升級為通用硬規則。

保留為：

> **流月對大運，是月度判讀的一個高優先初篩層。**

原因是大運代表當下長期背景，流月進來時，確實可以先看：

```text
流月是否與大運同柱。
流月是否沖大運。
流月是否合大運。
流月是否與大運共同形成更完整的刑沖合會。
```

但正式判讀仍要回到：

```text
原局 + 大運 + 流年 + 流月
```

不能寫成：

```text
流月只跟大運有關。
流月跟原局完全無關。
流月跟流年完全無關。
```

# 五、課程的三種高優先月運結構：保留結構，不保留固定吉凶

第一份文字稿把流月對大運的幾種明顯作用列為優先觀察，包括：

```text
流月與大運干支相同。
流月與大運形成明顯雙沖／反吟類作用。
流月與大運形成天干地支同時相合的雙合類作用。
```

其中字幕對術語「月運同途／反吟」等有辨識失真，因此本資料庫以結構描述為主，不強行定名。

更重要的是：課程曾把某些雙合直接論為不好，本資料庫不採固定吉凶。

統一：

```text
同柱 → 代表同一組干支力量在短時間被重複強調。
雙沖 → 代表變動、衝突或結構改變被放大。
雙合 → 代表綁定、合作、牽連或合住的力量被放大。
```

最後仍看：

```text
喜忌。
格局功能。
根氣。
十神。
宮位。
現實題目。
```

# 六、天干地支「上下生剋比和」：只用來描述過程

第二份文字稿提出一個從擇日法借入的簡化模型，把一柱干支內部關係分成：

```text
上生下：天干生地支。
下生上：地支生天干。
上剋下：天干剋地支。
下剋上：地支剋天干。
比和：干支同類五行。
```

課程把它延伸成「我幫人、人幫我、我控制、我受制、守成」等生活化比喻。

本資料庫只保留為：

> **月度互動過程的低權重描述工具。**

可用於描述：

```text
能量往外付出。
得到支持。
主動掌控。
受到約束。
維持原狀。
```

但不能直接用來判：

```text
一定成功。
一定失敗。
一定有人幫忙。
一定被人坑。
```

# 七、十九類干支複合關係：知道有這套系統，但不從破損字幕建表

第二份文字稿另提到一套更細的「十九類」關係，例子包括：

```text
天生地沖。
天比地沖。
天生地刑。
六合。
半三合。
```

這套方法是把兩柱的天干關係與地支關係疊加後分類，可用於流年或流月。

但本批文字稿沒有清楚列完十九類，加上大量干支例字 ASR 失真，因此：

```text
保留「存在十九類複合分類」的來源紀錄。
不建立完整十九類對照表。
不把個別例子的固定事件解讀升級為規則。
```

若未來取得原書、講義或清楚字幕，再另開專題補齊。

# 八、流月最有價值的地方：觸發與細節，不是事件全部成因

第一份文字稿有一個很好的現代化理解：

```text
破產不會一天形成。
重大衝突也不是某天突然無原因出現。
流月比較像把累積問題推到某個月浮現。
```

這與既有「事件鏈」完全一致。

資料庫正式整理為：

```text
累積期：原局、大運、前期流年逐步形成條件。
年度引動：流年讓題目進入今年主軸。
月度觸發：某流月使事件更集中、公開或需要處理。
後續期：事情可能跨月、跨年繼續處理。
```

所以：

> 流月可以幫忙找「哪個月更值得注意」，但不能把全部因果都歸給那個月。

# 九、流月適合用在哪些問題

文字稿把流月定位在「細節、近期、緊急時程」上，這一點可保留。

例如：

```text
工作：哪幾個月較可能出現面試、調動、簽約、交接。
財務：哪幾個月現金流、結算、付款壓力較集中。
合作：哪幾個月談條件、重簽、退出或重新分工。
感情：哪幾個月互動、確認關係、重新協商較明顯。
考試／資格：哪幾個月準備、報名、考試、結果公布。
```

若問題本身只問長期性格、人生大方向，流月權重反而很低。

# 十、問題尺度決定使用哪個時間層

第二份文字稿用不同問法說明：不是所有問題都需要把八字、大運、流年、流月全部同權使用。

本資料庫正式整理：

```text
問長期結構 → 原局最重要。
問十年階段 → 原局 + 大運。
問今年 → 原局 + 大運 + 流年。
問近期幾個月／已知日期附近 → 再加入流月。
```

這不代表較短時間層「比較準」或「比較重要」，而是解析度不同。

# 十一、流日：本課程止於流月，不代表其他流派不能使用

第二份文字稿明確說明，這套課程實務主要算到「月」，不再細分流日。

本資料庫記為：

> 這是本課程／流派的解析範圍，不是八字所有流派的共同限制。

因此不建立：

```text
八字絕對不能看流日。
流日一定沒有意義。
```

# 十二、「缺的五行逢流月補上」只能當短期引動，不能等於補用神

第一份文字稿提到：原局沒有的五行，可能在大運、流年、流月短期出現。

本資料庫保留：

```text
歲運可以帶入原局本來沒有或很弱的五行。
流月帶入的時間最短，作用通常也是短期。
```

但必須沿用核心規則：

> **缺什麼 ≠ 喜什麼。**

所以：

```text
原局缺水 + 流月見水 ≠ 自動變好。
女命原局少官殺 + 流月見官殺 ≠ 自動結婚。
原局缺財 + 流月見財 ≠ 當月一定得財。
```

先看這個五行是否為喜用、是否破格、是否能被日主承載。

# 十三、案例中的固定性別、財富與婚姻斷語不採

兩份文字稿後段出現大量古法或講者案例式斷語，例如：

```text
女命無官殺就沒有丈夫。
男命缺財一生錢不夠。
某歲數一定結婚。
某運一定發財。
固定十五年、三十年人生分段。
某流月一定出重大事件。
五年內一定倒楣幾次。
```

這些與資料庫既有原則衝突，全部不升級為核心規則。

只保留可重複使用的方法：

```text
題目分層。
歲運引動。
喜忌與承載。
時間窗口。
事件鏈。
現實驗證。
```

# 十四、高風險事件限制

文字稿出現死亡、事故、坐牢、官司結果等例子。

資料庫沿用既有限制：

```text
流月沖合 ≠ 死亡月份。
流月刑沖 ≠ 一定車禍。
流月官殺變化 ≠ 一定坐牢。
某月「不好」 ≠ 官司一定輸。
```

若使用流月做風險提示，只能轉成：

```text
檢查合約與期限。
保留現金流。
降低高風險操作。
注意交通與工作安全。
重要醫療與法律問題交由專業人士處理。
```

# 十五、流月判讀 SOP

後續正式看流月，可用：

```text
1. 先確認原局日主、月令、強弱、格局與喜忌。
2. 看目前大運的長期背景。
3. 看流年今年主要引動的題目。
4. 排出十二流月干支。
5. 先看流月與大運是否同柱、沖、合或共同成局。
6. 再看流月如何加入原局與流年的既有作用。
7. 看天干十神、地支根氣、宮位與刑沖合會。
8. 若只是半合、半會、暗拱，降低權重。
9. 區分累積、年度引動、月度觸發、後續處理。
10. 最後對照現實時間表，不做單月必然事件預言。
```
