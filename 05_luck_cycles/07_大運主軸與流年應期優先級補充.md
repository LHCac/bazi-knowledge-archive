# 一、原局提供「結構」，大運提供「階段」，流年提供「眼前引動」

文字稿最穩定的核心是：

> 命本身提供運程的架構，運程要配回原局使用。

資料庫正式整理：

```text
原局：底盤、格局、喜忌、長期可反覆出現的題材。
大運：十年左右的環境與階段主軸。
流年：年度引動與轉折。
流月：進一步縮小時間窗口。
```

因此所有歲運判讀都要回到：

```text
原局喜忌 + 大運背景 + 流年引動 + 現實情境
```

---

# 二、問「長期發展」時，大運權重高於單一流年

文字稿指出，若問題是：

```text
什麼時候真正進入事業上升期？
什麼時候比較可能建立長期成果？
失敗後還有沒有較長的翻身階段？
```

只靠單一流年不夠。

資料庫採用：

> **持續性的成長、事業建立、資產累積、生活階段轉換，優先看大運。**

流年比較適合回答：

```text
今年是否出現轉折。
今年是否有某個機會／壓力被引動。
今年哪個題材變明顯。
```

不採：

```text
一個好流年 = 從此發達。
一個壞流年 = 整個十年失敗。
```

---

# 三、歲運重複／同柱：解讀為力量重複放大，不固定吉凶

文字稿提到「歲運並臨」類情況，也就是大運與流年出現同一組或高度重複的干支力量。

資料庫統一：

```text
歲運同柱／高度重複
= 某組五行、十神、宮位與刑沖合會在該年被強調。
```

可能表現為：

```text
機會集中。
責任加重。
變動更明顯。
某個既有題目被放大。
```

但一定要再看：

```text
這組力量是喜還是忌。
是否有根。
是否破格或救格。
作用到哪個宮位與十神。
現實事件是否已經形成條件。
```

不採「歲運並臨必凶／必吉」。

---

# 四、原局＋大運＋流年共同完成刑沖合會：可提高年度權重

文字稿反覆用「八字一字＋大運一字＋流年一字」共同形成三合、三會、刑沖等例子。

這與既有資料庫方向一致，可正式保留：

```text
原局已有兩個條件。
大運或流年補足第三個條件。
→ 該五行／宮位／十神的年度引動權重提高。
```

但成立前要檢查：

```text
是否真的是完整組合。
月令是否支持。
有無沖破。
是否有相應透干與根氣。
是否真的成化。
該五行是喜還是忌。
```

不能看到三個字湊齊就直接翻譯成固定事件。

---

# 五、一個流年可以「有好也有壞」，不要只貼整年標籤

文字稿有一個實務上很重要的提醒：

> 同一年可能同時存在有利的合、會與不利的暗沖或其他牽制。

資料庫正式採用：

```text
流年評估不是：好年 / 壞年 二分。
而是：哪些主題受益、哪些主題受壓、哪個作用更強。
```

例如：

```text
工作有機會，但合作成本上升。
收入增加，但支出／責任同步放大。
關係升溫，但界線與承諾壓力也增加。
```

因此年度結論要寫成「結構組合」，不要只給單一吉凶標籤。

---

# 六、近期問事：今年與去年要優先串成時間線

文字稿再次強調，實務上判近期流年時，至少要把今年與去年放在一起看。

沿用資料庫事件鏈：

```text
去年：前因、累積、開始。
今年：引動、轉折、結果浮現。
明年：延續、收尾、修復或再轉向。
```

如果今年的刑沖合會只是延續去年已經形成的條件，就不能把事情全部歸因於今年。

---

# 七、年齡與人生階段是「應事轉譯器」

文字稿用幼年案例說明：同一個財、官、合沖符號，若命主年齡太小，不應直接翻成成人世界的財務、感情或職業事件。

資料庫採用：

```text
象意先存在。
現實落點再由年齡、身份、家庭角色決定。
```

例如：

```text
兒童的財星／官星引動 → 可能先落在家庭資源、父母安排、學校與照護。
成年工作者的財官引動 → 才較可能落在收入、工作、主管、責任、合作。
感情適齡階段 → 才提高關係與承諾題材的現實權重。
```

不採固定年齡事件表。

---

# 八、精確出生時間可能改變行運結構，不能忽略時柱校對

文字稿提醒：若出生時辰不同，某些合、沖、拱與大運互動可能完全不同。

資料庫採用：

> **若分析涉及精確大運起運、配偶宮、時柱、特殊格或關鍵歲運應期，出生時間必須優先確認。**

因此對只有模糊時辰的案例，應標示信度，不作精確年份的強斷。

---

# 九、固定循環口訣不升級為通用規則

文字稿出現多種高度固定的週期斷法，例如：

```text
某地支年每十二年固定是財運。
某地支年每十二年固定是壞運。
十二年內固定幾年好、幾年壞。
某十年劫財運只能拿到一半的錢。
```

本資料庫不採。

只保留：

```text
若某一支／十神反覆與原局形成同一有效結構，確實可能在相似歲運再次引動同類題材。
```

但每次仍需重新檢查：

```text
當時所處大運。
天干不同。
全局強弱變化。
喜忌是否改變。
現實身份與環境是否相同。
```

---

# 十、神煞與特殊結構不能替代歲運主軸

文字稿大量使用魁罡、天羅地網等特殊名稱。

沿用資料庫既有神煞規則：

```text
神煞 = 現象層。
格局／用神／刑沖合會／大運流年 = 主判層。
```

所以不採：

```text
魁罡直接決定職業或財富。
天羅地網直接等於災難、牢獄或人生必敗。
某神煞一出現就決定流年結果。
```

# 十一、大運流年合參 SOP

```text
1. 先確認出生資料與四柱。
2. 定日主、月令、強弱、格局、喜忌。
3. 找原局最重要的刑沖合會與根氣。
4. 確認目前大運帶來的十年主題。
5. 若問長期發展，先判大運是否有承載與流通條件。
6. 再看今年／去年流年如何引動原局與大運。
7. 檢查歲運同柱、雙沖、雙合、三合三會等強作用。
8. 同時列出有利與不利作用，不做單一吉凶標籤。
9. 依年齡與現實身份決定事件落點。
10. 必要時再加流月縮小時間。
11. 最後用已發生的現實事件校驗。
```
