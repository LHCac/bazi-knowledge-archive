# 05_luck_cycles：大運、流年、流月

本資料夾存放八字時間運勢資料。

## 已整理補充

- `00_行運取用總論.md`：建立大運流年必須回到原局喜忌、用神與格局判斷的基本規則。
- `01_太歲流年與歲君沖犯.md`：整理太歲、流年與原局作用的基本使用方式與限制。
- `02_起大運與小運法.md`：整理順逆行、起運歲數與小運等基礎方法。
- `03_命運分層與大運流年合參補充.md`：補充命／大運／流年的分層、不同種類的好運，以及原局＋大運＋流年共同完成三合時的年度引動判法與限制。
- `04_沖合定位與問題導向判讀補充.md`：補充沖合的來源層、十神宮位定位、具體問題拆解，以及「流年作用原局／大運」的新舊事件來源假說與使用限制。
- `05_刑沖合會連鎖與事件餘波補充.md`：補充沖的力量比較、半刑半合半會的低權重使用、連續年份的事件鏈，以及觸發年與後續餘波的區分。
- `06_流月定位與月運判讀補充.md`：建立原局→大運→流年→流月的四層時間架構，整理五虎遁定位、流月與大運作用、月度觸發、上下生剋比和與十九類複合關係的使用限制。
- `07_大運主軸與流年應期優先級補充.md`：補充長期發展優先看大運、年度轉折看流年、歲運重複放大、原局＋大運＋流年共同完成結構，以及同一年好壞並存的判讀方式。
