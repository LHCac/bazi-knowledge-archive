# 一、古法「先觀夫子」只保留為歷史分析框架

文字稿引用古法思路：女命常先看「夫、子」的興衰，也就是丈夫與子女。

本資料庫只把它保留為：

```text
夫星：傳統上以官殺看伴侶、承諾與關係壓力。
子星：傳統上以食傷看子女、產出、表達與養育互動。
```

但不採：

```text
女人的人生一定以丈夫、小孩為第一優先。
女人婚姻失敗就等於人生失敗。
女人只能有一次或兩次婚姻機會。
女命比男命更需要被婚姻評價。
```

現代分析應先問當事人真正關心的是：感情、婚姻、事業、財務、家庭、學習或其他人生目標。

# 二、「一事論一事」是本次最值得保留的方法

文字稿有一個很有價值的提醒：同一個十神有很多象意，但不能一次把所有象意全部套上去。

例如印星可以象徵：

```text
母親。
學習。
文書。
保護。
資格。
安全感。
```

如果當下問的是：

```text
學業 → 先看印的學習、資格功能。
母親 → 再看六親與宮位。
感情 → 看印是否影響官殺、食傷與日主承載。
```

所以本資料庫正式採用：

> 十神先依問題類型取象，不把所有六親、性格、財運、婚姻象意一次混在一起。

# 三、女命婚姻仍以官殺「清、雜、根、制化」為主

文字稿大量討論正官、七殺與官殺混雜。

與既有資料整合後採用：

```text
正官：穩定承諾、規範、名分型關係。
七殺：壓力、強烈吸引、控制感、強勢型關係。
官殺清：關係象較單純。
官殺混雜：不同關係需求、對象類型或壓力來源同時存在。
```

官殺混雜不能直接斷：

```text
一定外遇。
一定離婚。
一定多個伴侶。
一定婚姻失敗。
```

必須再看：

```text
去官留殺或去殺留官是否成立。
是否有印化殺。
是否有食神制殺。
官殺有沒有根。
日主能不能承受。
官殺是不是喜用。
```

# 四、明透與暗藏：可觀察「顯性／隱性」，不套固定年齡

文字稿認為官殺透在天干時，事情較容易被看見；藏在地支時，較偏內在或不公開。

這與既有「天干外顯、地支暗藏」規則可以整合。

可保留：

```text
官殺明透：關係議題、承諾、壓力較容易外顯。
官殺藏支：可能較內在、延後、隱性或需行運引動。
```

但不採文字稿中固定：

```text
年月透官殺 = 30歲前一定婚變。
日時出現 = 固定某十五年一定應事。
```

具體時間仍以大運、流年為主。

# 五、夫星有根、無根：先看關係結構是否有「落點」

文字稿反覆用「通根」來分辨夫星是否只是表面出現，還是地支也有支持。

本資料庫可轉化為：

```text
夫星透而有根：伴侶／承諾象較有落點。
夫星透而無根：象意可能較浮、較依賴外部條件或行運。
```

但：

```text
有根 ≠ 婚姻一定穩。
無根 ≠ 一定離婚。
```

還要看根強弱、月令、刑沖合會與喜忌。

# 六、夫星「旺衰、長生死絕」只作第二層氣勢參考

文字稿大量以十二長生談夫星旺、絕、衰等狀態。

本資料庫只保留：

> 十二長生可以補充夫星在某支的氣勢，但不能取代官殺本身的根氣、月令與全局制化。

不採：

```text
夫星坐絕 = 一定離婚、喪偶或丈夫無能。
夫星旺 = 一定嫁得好。
某個「孤鸞日」 = 一定婚姻失敗。
```

這類古訣只留作歷史象意。

# 七、合、沖、桃花：只描述互動方式，不直接做道德判決

文字稿對「合多」「桃花」「外桃花」「牆內牆外」等有很多強烈的女性道德評價。

本資料庫全部去除性別道德判斷，只保留中性結構：

```text
合：牽連、吸引、合作、黏著、關係綁定。
沖：變動、衝突、拉扯、距離改變。
桃花：社交吸引、外在魅力、人際注意度的輔助象。
```

不能直接寫成：

```text
合多 = 不貞。
桃花多 = 感情混亂。
女命比男命更怕合。
有桃花就一定有第三者。
```

感情判斷仍回到實際互動、投資程度、承諾、界線與行為。

# 八、父母、婆媳、子女等六親：只能輔助，不能從單一十神直接決定關係

文字稿會把財、印、食傷延伸到父母、婆媳與子女關係。

可保留的只有方法：

```text
十神 = 關係性質。
宮位 = 人生領域。
生剋 = 互動方式。
根氣與旺衰 = 力量大小。
```

不能直接斷：

```text
印在時柱 = 不會帶小孩。
才學高的女性 = 不會照顧家庭。
財印相剋 = 父母必失和。
某柱有某十神 = 婆媳必不合。
```

六親關係需要更多條件交叉驗證。

# 十、感情題的現代化 SOP

未來遇到女命感情或婚姻問題，可用：

```text
1. 先定日主、月令、強弱。
2. 看官殺清雜、根氣與喜忌。
3. 看日支夫妻宮與刑沖合會。
4. 看食傷、印、財是否改變官殺結構。
5. 看有無去留、制化、通關。
6. 再看大運流年是否引動。
7. 最後回到現實：主動性、穩定投入、承諾、價值觀、距離、溝通與界線。
```

桃花、孤鸞、長生死絕等只放最後輔助。
