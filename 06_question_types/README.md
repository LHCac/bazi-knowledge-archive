# 06_question_types：八字問事分類

本資料夾存放八字針對不同問題類型的分析方式。

## 已整理補充

- `02_女命婚姻官殺補充.md`：整理傳統女命官殺夫星、官殺混雜、食傷與印星對感情結構的影響，並加入現代使用限制。
- `03_健康壽夭與意外高風險斷語限制.md`：由 YT 文字稿雙重校驗後整理的健康、壽命、意外與六沖高風險斷語使用邊界。
- `04_女命古法夫子與現代使用限制.md`：整理古法「先觀夫子」、官殺根氣、明透暗藏、桃花與六親，並排除古代性別道德與固定婚姻斷語。
- `05_五行生剋過程取象與關係解讀.md`：把五行相生相剋轉為低至中權重的互動過程取象，並規定須在十神、宮位、旺衰喜忌之後使用。

## 預計分類

- 性格與心理
- 感情與婚姻
- 財運與投資
- 事業與職涯
- 學業與考試
- 健康與體質
- 家庭與人際
- 大運流年事件

## 使用方式

八字問事分類主要用於長期傾向與人生策略，不直接取代六爻的單一事件判斷。
