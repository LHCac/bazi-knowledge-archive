# 書面批命與完整命運合參模板

## 資料定位

本篇整理 2026-09-05 使用者提供的 YouTube 課程文字稿 `錄製_2026_09_05_11_49_37_146.txt`，重點不是增加新的硬斷，而是補充：

- 「看八字」與「批八字」的差異
- 如何把內部分析整理成可讀的書面輸出
- 同一命盤可以從不同已驗證主線切入，但不能跳過正式 SOP
- 當事人真正關心的問題要優先輸出
- 原局、大運、流年要分層合參
- 年齡與現實階段會改變同一象意的落點

本篇必須搭配：

```text
01_四柱看命標準流程.md
02_實戰快速判讀與提問邊界.md
```

---

# 一、「看八字」與「批八字」不是同一件事

課程把實務分成兩層：

```text
看八字：分析者自己建立完整判斷。
批八字：把分析結果整理成對方能理解、能帶走、能追問的文字。
```

資料庫正式採用：

> **內部分析可以很完整，外部輸出要有層次、有重點。**

所以不能把所有看到的十神、神煞、刑沖合會全部堆給當事人。

---

# 二、內部分析仍必須走完整 SOP

即使最後書面只寫幾個重點，內部仍要先完成：

```text
1. 排盤確認。
2. 日主。
3. 月令。
4. 強弱與根氣。
5. 天干透出、地支藏干。
6. 正格優先，必要時再看特殊格。
7. 用神、喜忌、病藥與救應。
8. 刑沖合會。
9. 大運。
10. 流年／流月。
11. 現實問題與時間線。
```

因此：

> **書面可以從某一個重點開始寫，但分析不能從某一個重點直接結束。**

---

# 三、書面輸出可以有不同「切入點」

課程示範同一命盤可以：

```text
從格局切入。
從調候切入。
從刑沖合會切入。
從神煞／特殊結構切入。
```

資料庫只保留這個「寫作方法」，不保留任何單一切入點的固定斷語。

使用條件：

```text
1. 該結構已經被正式 SOP 驗證。
2. 該結構確實是當下最重要主線。
3. 不與月令、強弱、格局、喜忌衝突。
4. 不以神煞取代子平核心。
```

例如魁罡、天羅地網等，若要寫入，只能作現象補充，不能直接決定人格、職業、婚姻、財富或災禍。

---

# 四、先寫「對方最關心的」，不是先寫「你最想講的」

課程反覆強調：實務上要依來問者真正關心的題目安排輸出。

資料庫整理為：

```text
問今年 → 先回答今年。
問工作 → 先回答工作與職涯決策。
問感情 → 先拆認識、互動、承諾、長期適配。
問財務 → 先回答收入、支出、風險、資源與時間窗口。
問長期發展 → 先看大運主軸，不只看單一流年。
```

避免：

```text
對方問工作，卻先講幾十年後婚姻。
對方問今年，卻花大量篇幅講童年。
把低信度神煞放在核心答案前面。
```

---

# 五、書面批命不是把理論名詞原封不動丟給對方

課程指出，口頭分析與書面批命的語言不同。

本資料庫採用：

```text
內部：可以用格局、相神、通關、制化、暗拱等專業語言。
外部：優先翻成清楚的現實描述。
```

例如：

```text
「官印相生」
→ 可寫成：適合在有制度、專業、責任與學習累積的環境發展。

「財被比劫牽動」
→ 可寫成：資源分配、合作成本或現金流競爭需要注意。
```

但不寫成：

```text
一定當官。
一定破財一半。
一定有小人。
```

---

# 六、同一象意要依年齡與現實階段落地

文字稿用幼年與成年案例說明：同一個財、官、合沖符號，在不同人生階段不一定落在同一事件。

資料庫正式採用：

```text
兒童：家庭環境、父母安排、學校、健康與照護。
學生：課業、師長、同儕、資格與壓力。
工作期：職責、收入、主管、合作、轉職與制度。
感情期：互動、承諾、界線、生活安排。
晚年：資產、健康、家庭角色、生活節奏。
```

所以：

> **十神／宮位／刑沖合會提供題材，年齡與現實情境決定實際落點。**

不採固定「某歲數一定發某事」。

---

# 七、原局是架構，大運是階段，流年是眼前引動

本批最值得保留的實務分層：

```text
原局：提供一生反覆出現的結構與可承載範圍。
大運：決定某十年哪些題材容易成為主軸。
流年：把其中某些題材推到眼前。
流月：必要時再縮小時間窗口。
```

因此：

```text
問「人生何時進入長期上升期」 → 先看大運。
問「今年會不會有明顯轉折」 → 看大運 + 流年。
問「近期哪個月比較明顯」 → 再加流月。
```

不能靠單一年份去定義整段人生。

---

# 八、書面批命建議格式

正式輸出可使用以下模板：

```text
一、命盤核心
- 日主、月令、強弱、主要格局。

二、最重要的結構
- 用神喜忌。
- 最明顯的十神與刑沖合會。

三、現實主題
- 工作／財務／感情／學業／家庭，依問題選擇。

四、目前大運
- 十年背景與主要機會／限制。

五、近期流年
- 今年、去年、明年的事件鏈。

六、必要時補流月
- 哪些月份較可能集中觸發。

七、風險與可操作建議
- 把象意翻成實際行動。

八、信度標記
- 高信度主線。
- 中低信度輔助象。
```

# 九、哪些內容不直接寫入核心結論

本批文字稿包含大量傳統斷語，本資料庫不採：

```text
缺某五行 = 一生留不住錢／一定無婚姻。
魁罡 = 固定職業、固定人格、固定財富。
全陽 = 固定人際結局。
某神煞 = 固定桃花、官非或家庭事件。
某十神在某柱 = 固定父母權力與家庭結構。
固定三十歲、四十五歲、五十五歲成敗。
固定收入金額與財富級距。
```

這些若保留，只能放在來源紀錄的「傳統／課程說法」，不得作通用規則。
