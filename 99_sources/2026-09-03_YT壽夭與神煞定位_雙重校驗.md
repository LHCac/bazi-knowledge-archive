# 二、第一次檢查：原始文字稿內部校驗


第一份文字稿中的：

```text

```

高度疑似在談「夭壽／夭殺」一類概念，但字幕品質不足以可靠確認全部術語，因此正式文件不自行還原成固定名稱或查法。

同樣地，第一份後半出現多組強弱、財殺、刑沖的專門公式，但字幕過度破碎，不把模糊內容重建成新公式。

## 2. 原稿內部可以直接保留的觀念

```text
A. 刑沖合會與神煞是不同層次的工具。
B. 神煞本身比較像「現象」，不直接等於命好或命壞。
C. 神煞要配合落柱、十神與其他結構理解。
D. 驛馬的核心是「動」，動本身有好有壞。
E. 華蓋可以延伸藝術、宗教、精神探索等象意。
F. 將星可以作決斷、主導與不易動搖的象意。
G. 原局結構若被大運流年再次引動，事件感可能更明顯。
H. 疾病、意外、集體事件不能完全當成同一類型處理。
```

## 3. 原稿自身已提供的反例

第一份文字稿先引用類似「年月沖、日時沖」的短命說法，但後面又明確表示自己親眼看過年月沖、日時沖者並沒有死亡，而且後續仍有正常社會發展。

這個反例非常重要，因此：

```text
年月沖 + 日時沖 ≠ 必短命
日時沖 ≠ 必死亡
```

不能把前面的古訣字面化。

同一文字稿後面又以飛機事故、海嘯等集體事件為例，指出不可能假設所有受害者的個人八字同時具有同一組凶象。

因此可保留：

> 個人八字不是公共災害、自然事件與所有隨機事故的完整因果模型。

# 三、第二次檢查：與既有 GitHub 核心規則交叉校驗

## 1. 與既有核心規則一致

既有資料已明定：

```text
沖不一定凶。
沖忌神可能為吉，沖用神或根氣才需要提高警覺。
神煞與貴人只作輔助，不能取代月令、強弱、格局與用神。
四柱位置只作人生領域參考，不宜單獨固定事件。
先原局，再大運流年。
```

因此本次新增內容不能把古訣、沖煞或神煞提升到核心判盤之前。

---

## 2. 與既有資料一致且值得補充的地方

### 神煞是「現象層」

這份文字稿有一句非常有價值的方向：

```text
神煞本身同命好壞無關，它首先是一種現象。
```

這與現有資料庫「吉神不一定吉、凶煞不一定凶」完全相容。

因此正式文件補成：

> 神煞提供現象與表現方式，主判仍由子平核心結構完成。

### 驛馬的「動」概念

文字稿對驛馬的說法可現代化為：

```text
旅行、搬遷、外勤、跨區域、工作變動、生活節奏移動。
```

這比直接把驛馬分成吉馬、凶馬更實用。

### 十神＋宮位＋神煞

文字稿嘗試把神煞和十神放在同一柱理解。

本資料庫保留方法，但改成：

```text
十神 = 性質
宮位 = 領域
神煞 = 現象補充
```

而不是直接用六親公式斷事件。

### 壽夭內容反而強化「不應單一斷死」

因為原講者自己的案例就否定了古訣的絕對性，所以本次最值得加入的不是「短命公式」，而是：

> 健康、壽命與死亡屬高風險題目，古訣必須降級為歷史象意，不能當現代確定預測。
