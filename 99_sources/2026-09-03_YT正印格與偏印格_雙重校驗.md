# 二、第一次檢查：原始文字稿內部校驗

## 1. 高信度詞彙還原

依上下文可高信度辨識：

```text
日祖 → 日主
正應／正硬／正義 → 正印
偏應／偏一／偏硬／偏隱 → 偏印
才 → 財
官商 → 官殺
死傷／舌傷 → 食傷
筆尖／彼間 → 比肩
節財／捷才 → 劫財
```

另外，偏印課程所說「天意貴人」依既有資料庫與語境判斷，應高度可能指「天乙貴人」；但正式整理時仍不把字幕誤字本身當成新規則來源。

## 2. 可直接保留的核心規則

```text
印為生我之神。
生我而陰陽相異為正印。
生我而陰陽相同為偏印。
官殺可生印。
財星可剋印。
正印、偏印表現方式不同，但都要回到命局強弱與喜忌。
同一印星落在不同四柱，象意與人生領域不同。
```

## 3. 可保留但降級成「性格／職涯觀察」的內容

```text
正印：較重正規學習、資格、禮貌、穩定與制度資源。
偏印：較重自學、特殊專長、研究、冷門知識、非標準方法。
正印明顯：可能較避免正面衝突、表達較迂迴。
偏印明顯：可能想法內收、話少、期待別人理解暗示。
正偏印同時明顯：可能有正規與非正規兩套學習／職涯模式。
```

以上只能作觀察假設，不作固定人格判決。

## 4. 原稿中不納入硬規則的內容

```text
正印格一定要有官殺才會成功。
正印一定是高學歷、教師、公務員或官場人物。
偏印一定是藝術家、醫師、命理師。
偏印女命一定婚姻差。
偏印一定不利小孩。
時柱偏印一定晚年孤獨。
日支偏印一定婚姻無話可說。
正印女命一定干涉丈夫與子女。
偏印一定要偏財，不能用正財。
偏印一定要特定貴人才會成功。
正偏印混雜就是雙重人格。
固定十五年分段可直接斷事件。
三十歲前可決定一生吉凶。
```

原因：上述多為單因果、性別公式、特定派別經驗或時代背景敘事，缺少日主強弱、喜忌、制化與行運條件。

## 2. 本次新增價值

本次文字稿真正值得加入資料庫的補充有：

```text
A. 正印與偏印可用「正規／制度化學習」與「特殊／自學研究」作現代辨識框架。
B. 正印的溝通風格可觀察禮貌、避衝突、間接表態；偏印可觀察內收、簡短、暗示式表達。
C. 偏印與財的關係，可現代化解讀為「特殊技能如何接上市場與資源」，而非簡化成橫財。
D. 正偏印混雜可先看多套學習、專業與職涯模式，不直接貼人格標籤。
E. 原課程其實多次提醒「性格不等於好命壞命」與「要依時代、人之常情處理」，這一點與資料庫現實優先原則一致。
```

## 3. 與既有資料衝突或過度延伸而被降級／排除的部分

### 正印格「一定要官殺」

既有資料只支持：

```text
官印相生為美。
官星可生印、印可護身。
```

因此修正為：

> 官印相生是正印常見有利配置，不是所有正印格成功的必要條件。

### 「偏印一定要偏財」

既有資料支持的是：

```text
印重時，財可制印。
財是否可用取決於日主強弱、印的喜忌與整體流通。
```

所以保留「偏印技能可透過財星落地」的概念，不保留「必須偏財」的硬公式。

### 「偏印一定要天乙／天德／月德」

既有貴人文件明定：

```text
吉神只作輔助。
不能取代月令、強弱、格局與用神。
```

因此不升級為成格必要條件。

### 女命與婚姻／子女的硬斷

原稿大量以古代性別角色與六親公式推導婚姻、子女、晚年。

本資料庫統一處理為：

```text
性別公式只作傳統參照。
不可用單一印星直接斷婚姻、生育、子女緣或晚年孤獨。
關係問題需回到夫妻宮、相關十神、行運與現實互動。
```
