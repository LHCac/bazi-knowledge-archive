# 三、兩份文字稿的主要內容

## A. 用神的語義與歷史敘事

課程主張「用神」在不同時代／框架曾有不同意思，大致描述成：

```text
有用之神／透出可用
→ 月令、十神、格局之用
→ 格局之間的調停、通關
→ 日主與格局的承載、強弱
```

本次不把這條歷史順序當作已考證事實，但保留其方法論價值：

> 不同文本中的「用神」未必同義，使用前要先定義語境。

## B. 月令與取用

課程多次把月／月令放在核心位置，並進一步談節氣內分日主事。

正式採用：

```text
月令是正格、季節氣勢與日主得令的重要起點。
```

不採固定分日天數表，原因是字幕不穩定且派別性高。

## C. 強弱其實有不同比較對象

課程區分：

```text
日主對格局的強弱。
格局／十神彼此之間的強弱。
```

正式文件進一步標準化為：

```text
日主強弱。
格神／十神強弱。
結構間強弱。
```

這是本批資料很有價值的新補充。

## D. 十二長生不宜當成精密重量

課程批評把十二長生像秤重一樣機械量化，較強調其「過程」性。

正式採用：

> 十二長生可以輔助觀察氣勢階段，不用來換算固定分數、財富或人格。

## E. 沖合要回到實際問題

第一份文字稿後段強調：

```text
「明年運氣好不好」
和
「明年與某人合作好不好」
不是同一題。
```

正式採用「問題導向」原則：先定問題，再看相關十神、宮位、喜忌與歲運作用。

## F. 流年作用原局／大運的「新舊事件」

課程提出：

```text
流年直接作用原局 → 偏舊題材。
流年主要作用大運 → 偏新題材。
```

保留，但降級為：

> 課程特定的「新舊事件來源假說」，低權重使用，必須由現實情況驗證。

# 四、第一次檢查後排除或降級

## 1. 命理史、書名、人物源流不直接入核心

原稿提出很多具體歷史主張，包括：

```text
「用神」詞源來自何人。
徐子平與《用神經》的關係。
若干古書如何失傳／抄傳。
明清不同年代如何改變用神定義。
台灣／中國不同地域流派傳播史。
```

因本次未做外部文獻查證，而且字幕的人名、書名、年代多處不穩，全部只列為「課程歷史敘事／研究線索」，不寫成正式歷史事實。

## 2. 固定四柱十五年分段

第一份再次出現：

```text
年柱 1～15。
月柱 16～30。
日柱 31～45。
時柱後段。
```

既有資料庫已將此降級為課程／流派輔助模型，本次不升級。

## 3. 「無根＝日主弱」的等號

第二份有強式說法：

```text
日主無根就是日主弱。
```

不採。

修正：

```text
無根是明顯減分，但仍要看月令、印比、生扶、合化與整局。
```

## 4. 身強身弱直接決定人格、慾望

原稿有：

```text
身弱沒願望。
身強有衝勁／野心。
```

不採為通用人格規則。

## 5. 十二長生固定人格

原稿把長生等階段延伸成固定衝勁、守成等人生風格。

只保留「階段／氣勢」概念，不固定人格。

## 6. 「沖不怕再沖、合怕再沖」

派別性過強，不採為硬規則。

修正為：

> 重複沖合時，要看第三方加入後是否改變原有結構、力量與喜忌。

## 7. 「真合一定比雙沖麻煩」

不採固定吉凶排序。

## 8. 極端身強／身弱直接連到送命、車禍

第二份後段明確把極端強弱與「送命、車禍、意外」連結。

與資料庫高風險規則直接衝突，全部排除。

不可使用：

```text
身強極端 = 車禍／死亡。
身弱極端 = 必有人禍。
無根 + 某星當令 = 必有重大事故。
```

只保留：

```text
極端強弱 = 承載、偏枯、流通問題需要提高注意。
```
