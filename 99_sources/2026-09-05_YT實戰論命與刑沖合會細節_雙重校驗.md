# 四、第一次檢查後可採用內容

## 1. 快速判讀只作「找重點」

第一份文字稿強調熟悉十神與刑沖合會後，要能快速從命盤找出最明顯的結構。

正式採用：

```text
先找強作用，再回完整 SOP 驗證。
```

不採「兩分鐘內一定要完成完整論命」作品質標準。

## 2. 問題導向與輸出邊界

第一份文字稿多次指出：

```text
同一張命盤，對方問不同問題，回答就不同。
沒有問、又離現在很遠的內容，不必全部講出來。
```

此原則與資料庫既有「問題導向」一致，正式加入實戰模板。

## 3. 流年不能只看單一年份

第一份文字稿明確提醒：

```text
今年爆發的事可能去年已經開始。
看今年時要回看去年。
```

第三份進一步補充：

```text
事件被某流年引動後，現實後果可能跨年持續。
```

因此正式新增「前因—觸發—餘波—修復」時間鏈概念。

## 4. 沖要比較兩方力量

第三份文字稿提出：同樣是沖，要看雙方強弱，而不是只看「有沖」。

正式採用為：

```text
比較得令、根氣、生扶、受制、喜忌與格局功能。
```

但不採「旺沖衰 = 弱方一定被沖掉」作機械規則。

## 5. 半刑、半合、半會只作輔助

第三份文字稿本身就把半刑定位為較弱、較少用的結構。

正式採用：

```text
不完整關係的權重低於完整三刑／三合／三會。
```

具體哪些兩支可算半合／半會、能否混合成局，派別性較高，加上字幕專名失真，因此不建立新的硬表格。

## 6. 連續年份要看連鎖

第三份文字稿提出：

```text
先合後沖。
先沖後合。
連續兩三年作用同一題材。
```

不能拆成「每年各自好壞」來看。

正式整理為：

```text
前因 → 引動 → 發展 → 餘波 → 修復
```

# 五、降級或排除內容

## 1. 固定四柱十五年／三十年／七年半

文字稿再次使用固定時間分段。

不升級，仍屬課程特定模型。

具體應期以大運、流年為主。

## 2. 固定感情對象數量

第一份有：

```text
一生固定幾個男人。
每隔固定幾年必有追求者。
某種暗拱一定是「有實無名」。
```

全部不作核心規則。

只保留「互動機會、吸引、曖昧、交往、名分、長期適配要分層」。

## 3. 婚姻與健康直接綁定

第一份後段有把某些婚姻結構直接延伸成身體狀況的斷法。

不採。

健康仍依資料庫既有高風險限制處理，現實醫療優先。

## 4. 冬至作命理換年核心

第一份字幕同時說：

```text
排八字換年以立春。
又另外提出「真正過年從冬至」的講者說法。
```

兩者層次不同且本批未做曆法、古籍外部驗證。

因此：

```text
不從此案例課新增冬至換年規則。
```

若要整理曆法邊界，另開專題查證。

## 5. 「先沖後合一定比先合後沖好」

只保留「相鄰年份具有連鎖性」。

不保留固定吉凶排序。

## 6. 「好流年出現，舊事才能結束」

只保留：後續歲運可能提供救應或新資源。

不採「一定等到三合六合年才結束」的硬規則。

## 7. 極端事件、死亡、法律結果等強斷

所有從單一刑沖合會直接推：

```text
離婚。
死亡。
破產。
犯罪。
官司結果。
```

均不升級為確定預言。
