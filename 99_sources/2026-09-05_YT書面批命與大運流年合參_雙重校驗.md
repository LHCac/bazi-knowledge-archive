# 四、第一次檢查後正式採用

## 1. 看八字與批八字要分開

採用：

```text
內部分析可以完整。
外部書面輸出應整理、精簡、依對方需求排列。
```

## 2. 書面可以從不同已驗證主線切入

可從：

```text
格局。
調候。
刑沖合會。
特殊結構／神煞。
```

作為寫作切入點，但不能跳過日主、月令、強弱、格局、喜忌的正式驗證。

## 3. 問題尺度決定時間層

採用：

```text
長期發展 → 大運優先。
今年 → 大運 + 流年。
近期月份 → 再加流月。
```

## 4. 原局提供架構，大運與流年完成引動

採用：

```text
原局本身先存在某個結構。
大運／流年若補足、沖開、合住或放大它，才形成時間性事件窗口。
```

## 5. 歲運同柱／高度重複可以提高作用權重

只採「重複放大」，不採固定吉凶。

## 6. 原局＋大運＋流年共同完成完整刑沖合會

採用為年度引動加權條件，但必須檢查是否真成立、是否成化、喜忌與力量。

## 7. 同一年可以好壞並存

採用：

```text
不能只看一個合就說全年好。
不能只看一個沖就說全年壞。
同一年要拆不同主題與力量比較。
```

## 8. 年齡與現實身份決定象意落點

採用：

```text
幼兒、學生、工作者、感情適齡、晚年，同一十神的現實事件不一定相同。
```

# 五、降級內容

## 1. 魁罡、天羅地網等特殊名稱

只作現象／特殊結構補充，不得凌駕核心子平分析。

## 2. 「暗拱／暗沖」直接推事件

沿用既有規則：暗象低於明象，只有在月令、根氣、歲運與現實驗證支持時提高權重。

## 3. 固定人生階段

文字稿使用三十歲、四十五歲、五十五歲等案例分段。

只視為案例／流派敘述，不作通用年齡應期。

## 4. 幼年事件由命盤直接推父母財務／婚姻

只保留「幼年象意常由家庭環境承接」的概念，不採具體父母事件硬斷。
