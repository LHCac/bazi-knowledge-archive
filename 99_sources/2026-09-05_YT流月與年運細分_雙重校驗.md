# 四、第一次檢查後正式採用

## 1. 流月是年度判讀的「時間細化層」

課程最值得保留的核心是：

```text
一年不是只有一個流年干支可以說完。
真正要把年度問題縮小到時間窗口，需要再看流月。
```

正式整理為：

```text
原局 → 大運 → 流年 → 流月
```

流月負責月度落點，不取代上層。

## 2. 五虎遁是流月排干支基礎

文字稿明確提到五虎遁，並指出五年六十個月形成一輪干支循環。

採用概念，不從破損字幕重建完整五虎遁表。

## 3. 流月可先對大運做高優先掃描

課程強調：

```text
流月與大運同柱。
流月與大運雙沖／反吟類。
流月與大運雙合類。
```

這些可作「月度強作用」的優先檢查。

但固定吉凶不採。

## 4. 流月是「觸發窗口」而不是全部成因

文字稿自己舉出：

```text
破產不會一天形成。
重大衝突也不是突然沒有前因。
```

正式接到既有事件鏈：

```text
累積 → 年度引動 → 月度觸發 → 後續處理／餘波
```

## 5. 問題尺度決定時間層

正式採用：

```text
長期結構看原局。
十年階段看大運。
今年看流年。
近期月份與已知時程再加流月。
```

這與資料庫既有問題導向完全一致。

## 6. 天干地支上下生剋比和可描述互動過程

第二份文字稿提出：

```text
上生下。
下生上。
上剋下。
下剋上。
比和。
```

只保留為低權重的互動方向描述，不用來直接判成敗。

## 7. 「十九類」只留系統存在，不重建表

文字稿可確認有一套把天干、地支兩層關係疊加的十九類分類，例子包含：

```text
天生地沖。
天比地沖。
天生地刑。
六合。
半三合。
```

但未清楚列完，且 ASR 失真，因此不建完整表。

# 五、降級內容

## 1. 「流月只與大運有關」

課程有非常強的表述：

```text
流月干支跟八字沒有關係。
流月跟流年沒有關係。
只跟大運有關。
```

此說法過於流派化，且與資料庫現有多層合參架構衝突。

降級為：

> 流月對大運可作高優先初篩，但正式判讀仍合看原局、大運、流年、流月。

## 2. 同柱／雙沖／雙合固定吉凶

課程部分段落把：

```text
某種雙合直接論不好。
某種雙沖直接論必有事。
```

不採固定吉凶。

保留「作用被放大」即可。

## 3. 流月補原局缺五行

只保留：

```text
歲運可以短期帶入原局本來少或沒有的五行。
```

但沿用核心：

```text
缺什麼 ≠ 喜什麼。
```

因此不能把流月補到某五行直接翻譯成吉事。

## 4. 本課程只算到流月、不算流日

記錄為本流派的解析範圍，不升級成八字通則。
